# NetFlex — Phased Implementation Plan

Estimates are engineering effort for one experienced developer, assuming owner answers arrive in time. They are planning aids, not commitments. Each phase ends only when its exit criteria are met with recorded evidence.

| Phase                     | Scope                                                                                                                                                                                                                                                                     | Exit criteria                                                                                                                    | Depends on                                              | Est.            | Key risks                 |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- | --------------- | ------------------------- |
| 0 Discovery               | Docs in this folder                                                                                                                                                                                                                                                       | Owner decisions + blockers documented; no invented hardware facts                                                                | Owner answers                                           | **in progress** | Slow owner answers        |
| 1 Foundation              | npm workspaces, strict TS, ESLint, Vitest, config validation, Prisma + first migration, docker-compose (Postgres/Redis), CI, pino logs + correlation IDs, design tokens, domain package (money, time, voucher codes, state machines)                                      | `npm ci && npm run lint && npm run typecheck && npm test && npm run build` green locally and in CI; migrations apply on empty DB | **Node.js + Docker (or Postgres/Redis) on dev machine** | 1–1.5 wk        | R17 toolchain             |
| 2 Identity & property     | Staff auth (password + TOTP MFA), tenant auth (OTP, test-only provider until A13), sessions (HttpOnly/SameSite, CSRF), RBAC, property/building/floor/room/zone, tenant assignments with history, group authority/membership, audit log (append-only, DB-level protection) | Permission matrix tests; cross-property/IDOR tests pass                                                                          | Phase 1                                                 | 2 wk            | OTP provider unknown      |
| 3 Plans, vouchers, orders | Plan + immutable versions, publish/pause/archive, server pricing, scope validation, voucher generation/issue/redeem with row locking, idempotency keys, orders                                                                                                            | Concurrency tests (parallel redemption can't exceed allowance); eligibility tests                                                | Phase 2; A3, A7–A9, A11 defaults                        | 2 wk            | Group policy ambiguity    |

Phases 1–5 can proceed without hardware. Phase 6 and live payment launch cannot.
